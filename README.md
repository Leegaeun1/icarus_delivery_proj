# 🥪 이거 진짜에요?

> 손님이 요청한 음식을 만들어서 올바른 배달원에게 전달하자!

## 🎮 게임 소개

샌드위치 가게를 운영하며 손님의 주문을 받고,
요청사항대로 음식을 만들어 **올바른 배달원**에게 전달하는 2D 시뮬레이션 게임입니다.
배달원의 면허 정보를 꼼꼼히 확인하지 않으면 잘못된 배달원에게 넘어갈 수도...👀

---

## 🕹️ 게임 진행 방식

1. 📋 **주문 접수** — 손님의 요청사항을 확인한다
2. 🥪 **샌드위치 제조** — 요청대로 재료를 조합해 포장한다
3. 🪪 **배달원 검증** — 면허증 정보와 등록 정보를 비교해 올바른 배달원에게 전달한다
4. ⭐ **평가** — 2일이 지나면 별점이 부여되고, 기준 이하 시 게임 오버!

---

## 👥 팀 구성 및 역할

| 이름 | 담당 역할 |
|------|-----------|
| 이가은 | 요리 제조 시스템, 기본 UI, 돈 관리 로직 |
| 이민지 | 스프라이트 디자인, 대사 관련 |
| 임태현 | 배달원 면허 확인 시스템 |
| 홍선영 | 매장 씬 구성, 주문 데이터 처리, 배달원 등장 연출 |
